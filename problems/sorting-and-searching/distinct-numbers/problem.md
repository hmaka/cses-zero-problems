# Distinct Numbers

You are given a list of `n` integers. Your task is to calculate the number of distinct values in the list.

## Input

The first input line contains an integer `n`: the number of values.

The second line contains `n` integers `x_1, x_2, ..., x_n`.

## Output

Print one integer: the number of distinct values.

## Constraints

- 1 ≤ n ≤ 2 · 10^5
- 1 ≤ x_i ≤ 10^9

## Example

**Input:**
```
5
2 3 2 2 3
```

**Output:**
```
2
```
