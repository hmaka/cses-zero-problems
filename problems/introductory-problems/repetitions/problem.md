# Repetitions

You are given a DNA sequence: a string consisting of the characters `A`, `C`, `G`, and `T`.
Your task is to find the longest *repetition* in the sequence: a maximum-length substring
that contains only one type of character.

## Input

The only input line contains a string of `n` characters.

## Output

Print one integer: the length of the longest repetition.

## Constraints

- 1 ≤ n ≤ 10^6

## Example

**Input:**
```
ATTCGGGA
```

**Output:**
```
3
```
