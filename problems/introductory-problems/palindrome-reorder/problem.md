# Palindrome Reorder

Given a string, your task is to reorder its letters so that it becomes a palindrome (it reads the same forwards and backwards).

## Input

The only input line has a string of length `n` consisting of the characters `A`–`Z`.

## Output

Print a palindrome consisting of the characters of the original string. You may print any valid solution. If there is no solution, print `NO SOLUTION`.

## Constraints

- 1 ≤ n ≤ 10^6

## Example

**Input:**
```
AAAACACBA
```

**Output:**
```
AACABACAA
```
