# Two Knights

For each `k = 1, 2, ..., n`, count the number of ways to place two knights on a `k × k` chessboard so that they do not attack each other.

## Input

The only input line contains an integer `n`.

## Output

Print `n` integers: the results for `k = 1, 2, ..., n`, one per line.

## Constraints

- 1 ≤ n ≤ 10000

## Example

**Input:**
```
8
```

**Output:**
```
0
6
28
96
252
550
1056
1848
```
